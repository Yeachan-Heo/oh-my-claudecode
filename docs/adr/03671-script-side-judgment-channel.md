# Script-side judgment channel: subprocess over stdin JSON

Plain-Node hook scripts (workflow-drift-guard, post-tool-verifier) deliberately cannot import TypeScript — they must run before a build. To let them consult the judgment resolver without breaking that invariant, the resolver is invoked through a one-shot child process that reads a JSON request from stdin and writes a JSON result to stdout. Latency budget (owner to confirm): gate-type calls ≤250ms (matching OMC_JEV_TIMEOUT_MS); detector-type calls 0ms — fire-and-record from the script, never blocking the tool path. Rejected: in-process TS imports (breaks the pre-build invariant); long-lived local daemon (operational surface a hook layer should not own). Status: proposed — awaiting owner decision on the latency budget.
