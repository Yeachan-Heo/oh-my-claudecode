## Execution Notes For Later Tasks

- Treat LazyCodex tests and AGENTS files as contract authorities. README prose can explain intent but should not override `AGENTS.md` or test assertions.
- Generated or cached artifacts are read-only for port work unless a later build task explicitly owns regeneration: `dist/`, component `dist/`, generated bridge files, generated MCP bundles, and packaged runtime mirrors.
- LazyCodex paths that contain Codex-only concepts must be translated to Claude-native equivalents: lifecycle events, model IDs, tool APIs, subagent/session metadata, and stop/compact behavior.
- Unsupported parity must be recorded as staged with a concrete reason, not left implicit.
