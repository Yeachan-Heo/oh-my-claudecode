# Bro

Say the last message again, plainly.

## Rules

- Keep every fact and every number; drop every acronym the user has not
  used, every codename, and every piece of scaffolding vocabulary.
- One thought per sentence. Short sentences win.
- Name who or what each actor is the first time ("the test runner — the
  program that checks the code") and then use the plain name.
- If something in the original was wrong or overstated, say so while
  restating; plain language is not a chance to launder a claim.
- Length: however many plain sentences the facts need — terseness that
  drops content is not plainness.
